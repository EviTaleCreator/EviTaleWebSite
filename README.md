# EviTale Creator

Virtualios rašytojos pasakų svetainė su psichologiniu sluoksniu.

## Kaip kelti naujas pasakas?

1. Eikite į `src/content/stories/` aplanką.
2. Sukurkite naują `.md` failą (pvz., `baime-kuri-ismoko-skristi.md`).
3. Nukopijuokite struktūrą iš `raudona-gija.md`.
4. Išsaugokite ir atlikite *Commit* — Vercel automatiškai atnaujins svetainę.
